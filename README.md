# V2 Pilot

Test template for BudStacks Template Design System v2. It exists to check the
pipeline end to end (skill → validator → upload → preview); it is not a
marketplace template.

Brand: "Pilot Clinic", a fictional clinic. The two photographs are borrowed
from the HealingBuds template.

Upload: BudStacks super admin → Templates → Upload, with this repository's URL
and the template name **V2 Pilot** (the name becomes the slug `v2-pilot`).

Validate: `node <budstack-template-skill>/scripts/validate-template.mjs .`
